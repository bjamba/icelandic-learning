# Icelandic for Travelers

**Designed by Claude Code** · [GitHub](https://github.com/) · [Credits](credits.html)

> "I want to be able to order coffee, ask for directions in Reykjavik, introduce myself to locals, and handle basic daily situations in Icelandic during my trip."

## 🎯 Objective

By the end of this course, you'll be able to:
- Greet people formally and informally
- Order food and drinks at restaurants
- Ask for directions and understand responses
- Shop with confidence
- Handle emergencies
- Engage in simple conversations

## 📅 Timeline

- **Daily:** ~15-20 minutes
- **Module 1:** 2 days (Greetings)
- **Full curriculum:** ~2 weeks
- **Total:** 45 phrases, 6 modules, 6 exercises

## 💰 Cost

Free — everything runs in your browser, no accounts needed.

## ⚡ Quick Start

1. Open `index.html` (or visit the GitHub Pages URL) to see your progress
2. Start with Module 1: Greetings & Introductions
3. Practice with the phrasebook tool
4. Track your streak!

## 🛠️ Tools

- **Phrasebook** — Search and play audio for Icelandic phrases
- **Currency Converter** — Real-time ISK to USD/EUR converter
- **Flashcards** — Review phrases with audio

## 📱 Device

Responsive design — works great on phone, tablet, or desktop.
