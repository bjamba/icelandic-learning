Accessibility

The design system follows these accessibility principles:

  • Contrast: Body text meets WCAG AA (4.5:1 minimum)
  • Touch targets: Minimum 44px for all interactive elements
  • Keyboard nav: All interactive elements focusable
  • Focus styles: Visible focus indicators on all focusable elements
  • Reduced motion: Animations respect prefers-reduced-motion
